## 🔥 Kenapa Pilih SSB?

| ❌ Cara Lama | ✅ Dengan SSB |
|---|---|
| Rekod dalam buku tulis / Excel | Dashboard digital interaktif |
| Kira denda secara manual | Denda dikira **automatik** |
| Tanya satu-satu siapa dah bayar | Semak status bayaran **real-time** |

## ✨ Ciri-Ciri Utama

### 🏢 Modul SSB PRO — Untuk Penyelaras / Pengurus

> Urus semua kumpulan, ahli, bayaran & giliran dari satu tempat.

| Ciri | Keterangan |
|---|---|
| ⚙️ **Tetapan Kumpulan** | Cipta unlimited kumpulan dengan nama, penyelaras, jumlah ahli, caruman & denda lewat |
| 🔄 **3 Kekerapan Bayaran** | Pilih antara **Harian 🟢**, **Mingguan 🔵**, atau **Bulanan 🟣** untuk setiap kumpulan |
| 👥 **Senarai Ahli** | Daftar ahli dengan maklumat lengkap — telefon, emel, akaun bank, catatan |
| 💳 **Rekod Bayaran** | Rekod bayaran pantas — sistem auto kira caruman, hari lewat & denda |
| 🏆 **Jadual Giliran** | Tetapkan siapa menang, bila terima wang, jumlah & status |
| 📊 **Status Bayaran** | Paparan bulan demi bulan — BAYAR ✅ / LEWAT ⚠️ / BELUM ❌ |
| ⚠️ **Laporan Lewat** | Senarai ahli yang lewat bayar + jumlah denda terkumpul |
| 📥 **Export Excel** | Muat turun semua rekod bayaran ke Excel/CSV dalam satu klik |

### 👤 Modul Sertai SSB — Untuk Ahli / Peribadi

> Ahli boleh pantau simpanan peribadi mereka sendiri.

| Ciri | Keterangan |
|---|---|
| 👤 **Profil Saya** | Simpan maklumat peribadi — nama, telefon, bank |
| 📋 **Senarai SSB** | Lihat semua kumpulan yang disertai + status (Aktif/Selesai/Keluar) |
| 💳 **Rekod Bayaran** | Catat & pantau bayaran peribadi — tarikh, cara bayar, status |
| 📅 **Giliran Menang** | Jejak bila giliran anda, jumlah wang & status terima |
| ⚠️ **Laporan Lewat** | Lihat rekod bayaran lewat + denda untuk tindakan segera |

## 💬 Soalan Lazim (FAQ)

**❓ Boleh guna pada telefon?**
> Ya! Sistem ini 100% responsive — boleh diakses dari telefon, tablet, atau komputer. Tiada perlu install apa-apa app.

**❓ Berapa ramai ahli boleh masuk?**
> Tiada had! Anda boleh cipta unlimited kumpulan dengan unlimited ahli. Database mampu menampung ratusan ribu rekod tanpa masalah.

**❓ Bagaimana nak install?**
> Hanya 3 langkah — unzip, install, jalankan. Boleh siap dalam masa 3 minit sahaja. Kami juga sediakan bantuan pemasangan jika diperlukan.

**❓ Data selamat ke?**
> Ya. Sistem menggunakan authentication selamat, database tahan crash, dan data integrity terjamin. Mudah untuk backup.

**❓ Boleh tukar warna / tema?**
> Ya! Branding asas (nama syarikat, telefon, tagline) boleh ditukar dengan mudah.
